# Animation Codec Fixtures

Project-owned samples generated by `../../AnimationCodecFixtures.cs`. No downloaded images
or new codec dependency is used. `SkiaImageFrameSessionTests` validates actual decoder pixels,
frame metadata, loop semantics and resource release before exporting successful samples.

Set `MIV_FORMAT_FIXTURE_DIRECTORY` when running the existing UI codec tests. The successful
tests export the four files below, per-file `.sha256` records and `animation-codec-README.md`
into that directory. They can be consumed by `scripts/measure-animation.ps1 -FixtureDirectory`.
Multipage TIFF and static control images are exported by their existing tests.

## Generation And Pixel Oracles

GIF uses a four-color global palette: transparent black, red, green and blue. The minimal
test encoder emits a clear code before each literal, keeping code width fixed at three bits.
Every frame declares palette index zero transparent. The five small frames exercise partial
rectangles, transparent pixels, nonzero offsets, restore-previous and restore-background.
Their raw delays are all 30ms. Netscape repeat count zero means infinite playback.

The large GIF contains three centered 1024x1024 rectangles at source offset (1536,1536),
colored red, green and blue, with raw delays 50/70/110ms. Blue restores the background.
Its source-equivalent BGRA workspace is 64MiB, below the 92MiB playback admission bound.
Tests decode sequential and random frames to a 1024x1024 canvas and compare every BGRA row:
a 256x256 colored rectangle at (384,384), with all remaining pixels transparent. Restart
and first-frame representative pixels are checked before export. This is a playable sample;
the separate over-limit 8192x4096 regression is not exported for playback observation.

WebP payloads are encoded losslessly with the pinned SkiaSharp encoder. The test generator
writes explicit RIFF/VP8X/ANIM/ANMF headers. Frame zero is opaque red across the full canvas;
frame one overlays half-transparent green on its left half, then restores the background;
frame two writes opaque blue on the right half using Source blend. Delays are 30/10/40ms;
the session normalizes the 10ms delay to 100ms. Tests compare full composited BGRA arrays,
including the (0,128,127,255) green-over-red pixels and transparent cleared left half.
ANIM loop zero is infinite; loop two means two total plays. The declared white ANIM
background is intentionally decoded using the current Skia transparent-background semantics.

Output pixel budgets do not bound all native workspace, encoded-input copies, surfaces or
process memory. These generated samples and short codec tests do not prove long-run peaks
or cancellation latency inside a running native call.

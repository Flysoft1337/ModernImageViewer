## 3. 功能补全

### 3.1 近期浏览能力

- **打开入口统一：** 已实现文件选择、拖放和命令行共用管线、多选策略与窗口复用；MSIX 激活适配随后接入，详见文件关联方案。
- **日常文件操作：** 在资源管理器中定位、复制文件/图片、可复制的信息字段；近期先做读取与定位。删除、重命名随后加入，删除默认进回收站，失败保留当前显示和导航。
- **导航设置：** 开发代码已增加名称/修改时间/大小排序及升降序，默认自然名称排序，切换保留当前文件/视口，多选保留输入顺序。属性失败末尾、同键稳定排序，N2 已跨启动保存排序。
- **窗口与偏好：** N2 已保存正常窗口位置/尺寸/DPI/最大化、缩略图/信息面板状态和幻灯片间隔，350ms 合并写入、关闭 flush；显示器移除时限制在可见工作区，不保存全屏临时边界。恢复 HWND 使用物理坐标，真实混合 DPI 硬件交互待验收。不自动打开历史文件，最近记录若增加需可清空、可关闭。
- **剪贴板：** 文件列表输入已接入Ctrl+V/菜单，复用128项限制与多选序列；位图输入与整图预览/受限原尺寸复制已接入；内存来源没有原文件路径，不伪造目录导航或覆盖保存目标。透明像素、尺寸与大图预算与文件来源一致。
- **加载与恢复：** 加载可取消、错误可重试或跳过；不支持、损坏、权限拒绝、文件消失分别提示。当前已有错误分类与旧图保留，后续补操作入口和文件夹枚举错误的准确反馈。

### 3.2 格式、元数据与颜色

0.3.0 已通过统一格式目录补齐 JPEG/PNG/BMP/GIF/TIFF/ICO/WebP 静态读取，9 个扩展名同步用于选择器、导航、关联和打包。WIC负责原六类及本轮JPEG XR，Skia负责WebP；本轮受限SVG使用固定Svg.Skia。本批加入固定Magick.NET静态AVIF/HEIF与LibRaw预览桥接，未加入libvips；PNG/JPEG/WebP文件导出已接入，比例裁剪/WebP边界见[编辑补全](editing-improvements.md)，首批验证见[格式与编辑记录](raw-modern-editing.md)。动画和多页作为独立能力交付，不能把第一帧解码标成完整动画支持。文件签名探测与扩展名不一致时给出明确结果。

随包Skia仍不支持HEIF/AVIF，本批改用固定Magick.NET实测接入；RAW只提取LibRaw内嵌预览。受限SVG沿用，不代表完整SVG或显影；native实际分发/源码/完整许可与样本单独记录。

色彩管理单独推进：读取 ICC、无 profile 按 sRGB 解释、转换至显示器 profile、跨屏重新选择 profile，导出默认嵌入 sRGB。当前 WIC EXIF 方向纠正不代表 WebP EXIF、ICC 或 HDR 已支持；16-bit、CMYK、广色域和 HDR 行为要明确记录。元数据展示支持选择复制，GPS 不主动联网解析。

### 3.3 编辑与导出

N2 已提供会话旋转/翻转，作用于 EXIF 校正后的原图，预览/区域共用绘制矩阵，切图重置；不是文件编辑或导出。N6文件首批已引入不可变操作链、撤销重做、裁剪、Resize/Stretch和PNG/JPEG/WebP新文件导出，源与已有目标均不覆盖；剪贴板来源已接入，固定比例裁剪/WebP品质导出见[编辑补全](editing-improvements.md)。尺寸、质量、元数据移除和 ICC 策略应集中在导出面板。

编辑预览不得修改共享源像素。开发基线已补任意角度、调整、标注与预设，预览/导出共用Rendering。输出先写临时文件再提交，只创建新文件；关闭保护未导出修改，取消/失败保留编辑。摄影信息采用白名单，RGB ICC转sRGB，显示器/原profile与高位深仍未完成；资源和实际验证见[编辑能力](editing-improvements.md)。覆盖原文件和批处理留后续。

## 5. 性能优化

### 5.1 已有基础及实际边界

- 启动已移除 Generic Host，窗口先显示，Skia 控件延迟到首次图片；后续关注首次图片初始化而不是重复引入启动优化。
- 主画布已共享解码数组，少一份完整渲染像素副本；WIC 转换、方向变换、原生解码和 surface 仍可能有其他分配，不能称整个管线零拷贝。
- 主图预览与按需全尺寸细化共用单槽，支持排队取消和过期结果丢弃；在执行中的 WIC/Skia 原生调用不保证立即中断，开发基线补 WIC 有界区域，但仍需测量取消延迟与 codec 内部峰值。
- `ImageDecodeLimits` 的原始尺寸 32768、像素数 100MP 和基础单图输出 400,000,000 字节限制继续适用。开发预览按视口DIP×DPI选择，单边4096/32MiB，未布局回退2560×1600；浏览管线160MiB主图输出预算预留两份预览及4MiB邻图，完整细节最多92MiB。完整细化不足时 WIC 可显示有界区域、WebP 保持预览。不包含 native、surface、缩略图，不是全管线/进程预算；公开v0.4.0仍用固定预览与128MiB预算。
- 目录枚举和排序已后台执行；直接单文件先显示主图再索引，避免首图等待全目录。打开文件夹仍需先枚举候选，因此超大目录文件夹首屏仍有缺口。0.4.0 主图已先展示有界预览，再按需细化；不自动为每张图解码完整像素。
- 缩略图已按保留像素字节计费，2MiB/24 项 LRU，键包含路径、修改时间和长度；F5 代次使旧在途结果失效。元信息后台读取；没有持续文件监听，不保证同修改时间/长度的内容变化自动失效。缓存预算不含在途/可见缩略图及 native 工作内存。BenchmarkDotNet 当前仅覆盖像素数计算。

- 开发基线 WIC 最多请求 2048×2048 中心视区，输出最多 16MiB，约 160ms 去抖，保留一个区域并丢弃过期任务；不先分配完整托管 BGRA，但 codec 内部可能解码整图。不是完整分块缓存，4K/高 DPI 视区未被中心区域覆盖的部分仍显示预览。WebP 未接区域路径。
- 开发基线按导航方向预取一张最多 1280×800/4MiB 预览；文件属性在解码前后和使用前复核，F5 清理，取消/过期结果释放。解码槽忙时跳过，不排队/重试；前台仍可能等待已开始的原生调用。

### 5.3 测量与验收

以[项目计划的指标](project-plan.md#102-指标)作为目标，不将其标成当前已达标。保留现有启动 smoke，优化阶段在固定 Windows 机器比较前后 Release self-contained 包，记录提交、系统、CPU/RAM/磁盘、DPI、包配置、样本与观察窗口。

启动区分冷/热与首次启动；记录窗口可交互、首个可辨认画面、完整图完成。快速脚本默认 3 次、CI 1 次的结果只用于观察，不用来宣称 P95。阶段性能验收建议热启动/切图至少 30 次；冷启动记录受控重启条件和样本数，样本不足时列原始结果，不给可靠性不足的 P95 承诺。

样本至少含空窗口、4K PNG、24MP JPEG、100MP 图、透明/EXIF 图和万级目录。检查工作集、私有字节、托管堆、native 分配、峰值与取消后稳定值；连续浏览 500 张并观察缓存逐出后的趋势。正常交接可能暂存旧图和新图，应报告峰值而非只看打开后的工作集。

日常变更保持验证精简：文档/视觉调整只做相应检查；涉及像素生命周期、取消、缓存、导出和安装路径才补针对性回归。复用已有 CI，性能优化不扩展为每个 PR 的全量测量矩阵。

## 6. 完成标准与暂缓范围

每个工作包交付实现、用户说明和简短验证记录。支持新格式同时更新能力表与关联列表；界面优化附原生截图；性能优化附可复现条件和前后数据。记录目标值与观察值的差别，未实现入口保持隐藏。

M1 收尾需浏览主路径、文件关联、格式边界、DPI/键盘和性能基线明确；M0 高风险技术验证按能力推进，未通过的 codec/大图/ICC 不能进入正式支持。基础编辑从 M2 开始；批处理、复杂 Shell 扩展、多窗口、OCR、插件与图库数据库不进入近期工作包。

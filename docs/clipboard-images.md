# N3 剪贴板图片与内存来源

> 2026-10-06，开发0.5.0，公开下载仍v0.4.0。本批不发布Release；[PR #28](https://github.com/Flysoft1337/ModernImageViewer/pull/28)功能提交d501ac2的[Windows CI](https://github.com/Flysoft1337/ModernImageViewer/actions/runs/37341778600)已通过；最终合并状态见PR。

Ctrl+V/“更多 → 从剪贴板打开”支持文件列表、PNG透明数据和兼容位图。文件列表优先（最多128项），PNG优先于Bitmap；没有图片、占用、损坏或超限时保留当前图片。文本输入保留自身复制/粘贴。位图来源有独立身份、无文件路径，成功打开后清理导航/邻图预取，禁用文件定位、复制路径和排序；同尺寸新粘贴重置视口，细化保留视口。

## 资源与能力边界

- 源边长≤32768，BGRA等价和实际源位图载荷≤64MiB（最多16,777,216px），PNG编码≤32MiB；暂不接受高位深PNG/位图。这是应用载荷限制，不是native或整个进程硬上限，剪贴板提供方自身可能先分配更多数据。
- PNG在STA只读取头/有界快照，后台解码并缓存冻结来源；BitmapSource直接冻结，避免在粘贴时复制一份完整托管源。预览最大2560×1600（最多16,384,000B），按需细化读取完整输出，过期/取消结果释放。
- Ctrl+C复制整张图预览，旋转/翻转作用于当前主图，排除UI与中心ROI。缩小用预乘BGRA双线性采样；没有方向变换且不缩小时复用既有数组。复制原尺寸仅当完整像素已加载且输出≤64MiB时启用；不会为复制自动解码超大完整图。
- 后台生成PNG透明流与兼容Bitmap，回STA持久发布前检查取消；新打开/关闭取消晚写。必要的WPF/native/系统格式副本仍存在，不宣称零拷贝。兼容Bitmap的Alpha在其他软件中可能表现不同，不以注入writer回归代替外部应用互通验收。
- 内存图片可Ctrl+E编辑、撤销重做并另存PNG/JPEG；后续已扩展WebP，见[编辑补全](editing-improvements.md)。编辑按需完整读取≤64MiB，或复用已加载完整只读数组；关闭释放引用。源/输出各≤64MiB、已有目标拒绝，临时CreateNew→flush→Move不覆盖；不制造临时源路径。

## 决策原则

- 浏览响应、低内存、UI 美观与原图安全优先；PR #21 已完成 B 的 WIC 有界区域、C 紧凑/沉浸 UI 和 D 邻图预览；N1 日常浏览已接入，下一批推进 N2 会话方向/偏好，同时继续全管线预算与固定机实测，不触发新 Release。
- 区分已实现、部分实现与目标；原生 codec 和发布能力逐项验证。
- 性能记录明确 Windows 条件与样本数，不用单次 CI smoke 宣称冷启动、首帧或 P95 达标。
- 保持验证精简，复用既有 CI；高风险内存、导出、激活逻辑补关键回归。

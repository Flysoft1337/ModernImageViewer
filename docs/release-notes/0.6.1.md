# ModernImageViewer 0.6.1

补丁候选，尚未发布。保留0.6.0的格式、动画、多页和编辑范围，不增加功能；公开v0.6.0资产不变。

## 修复与改进

- 修复深浅主题菜单背景、旋转图标、勾选与图标布局、重复F6/F11提示；小窗口菜单支持滚动，保留键盘焦点反馈。
- 改善大PNG反复缩放细化：预算允许时保留完整细节，复用已覆盖的区域及在途请求，避免重复解码。完整静态细节最多124MiB，静态主图缓存192MiB；不是整进程内存上限。
- 自带.NET 10/WPF的运行文件集中在`app/`，托管程序集压缩，native依赖外置；许可证和必要源码在`licenses/`。不使用WPF trimming，便携入口改为`app/ModernImageViewer.App.exe`。
- 旧散装布局仅按已知EXE、安装标记及逐文件SHA256清理，保留未知或修改过的文件。升级已注册关联时，即使未重新勾选关联任务也迁移入口；安装版与便携版身份保持独立。
- 修复CI性能观察子进程`exit 1`的处理。只有报告完整的前台焦点环境失败可记为Inconclusive；真实错误、超时和有效性能超阈值仍阻断。历史/压缩对照使用同机同SDK/runtime的交替观察，不作为P95。

## 已知限制

完整真实桌面视觉、鼠标与Shell人工验收尚未完成。CI/资源计数不能代替人工检查，也不证明整个进程绝不泄漏。压缩包的安装后占用减少，不保证安装器下载体积同步减少。保留[0.6已知限制](../known-limitations.md)中的RAW预览、色彩、高位深、动画预算、未签名安装器和Win-x64边界。

本补丁不纳入PR #41的OpenGL依赖移除，保留现有Skia WPF声明的依赖。验证证据、发布判断及人工缺口见[收口验收](../release-closeout-0.6.1.md)；正式发布须满足最终master完整CI及人工/性能验收要求。

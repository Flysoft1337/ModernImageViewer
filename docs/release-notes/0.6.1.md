# ModernImageViewer 0.6.1

0.6.1是菜单、大图细节复用与安装体积的补丁版本，保留0.6.0的格式、动画、多页和编辑范围。公开v0.6.0资产不变。

## 修复与改进

- 修复深浅主题菜单背景、旋转图标、勾选与图标布局、重复F6/F11提示；小窗口菜单支持滚动，保留键盘焦点反馈。
- 改善大PNG反复缩放细化：预算允许时保留完整细节，复用已覆盖的区域及在途请求，避免重复解码。完整静态细节最多124MiB，静态主图缓存192MiB；不是整进程内存上限。
- 自带.NET 10/WPF的运行文件集中在`app/`，托管单文件、native依赖外置；许可证和必要源码在`licenses/`。同机交替观察确认程序集内部压缩影响启动，0.6.1关闭内部压缩，继续用ZIP/安装器压缩下载。不使用WPF trimming，便携入口改为`app/ModernImageViewer.App.exe`。
- 普通CPU绘制只使用`SKElement`，按已核验包版本排除未使用的OpenTK/GLWpfControl及GLFW；保留Skia、WPF及图像native依赖。安装器采用LZMA2/max和32MiB字典，ZIP使用SmallestSize；只改变分发压缩，不恢复程序集内部压缩。旧`app/glfw3.dll`仅在安装标记及文件哈希匹配时回收，修改过的文件保留。
- 旧散装布局仅按已知EXE、安装标记及逐文件SHA256清理，保留未知或修改过的文件。替换旧卸载日志，避免卸载时误删升级已保留的修改旧文件；重装沿用已有且归本安装所有的桌面入口。升级已注册关联时，即使未重新勾选关联任务也迁移入口；安装版与便携版身份保持独立。
- 修复CI性能观察子进程`exit 1`的处理。只有报告完整的前台焦点环境失败可记为Inconclusive；真实错误、超时和有效性能超阈值仍阻断。历史/压缩对照使用同机同SDK/runtime的交替观察，不作为P95。

## 已知限制

完整真实桌面视觉、鼠标、Shell、混合DPI及长期压力人工验收尚未完成。CI/资源计数不能代替人工检查，也不证明整个进程绝不泄漏。下载体积、载荷和安装后占用分别记录；本补丁没有采用约125MB的内部压缩安装试包。RAW仅内嵌预览，AVIF/HEIF仅静态首图；显示器ICC、HDR/高位深和完整RAW显影未支持。动画缓存有预算限制；安装器未签名，仅提供Windows x64包。

历史最终master的有效6对切图对照曾超过10%门槛，后续有6对有效通过及失焦结果；性能波动原因尚未完全定位，不保证所有设备无退化。原始失败保留在[收口验收](https://github.com/Flysoft1337/ModernImageViewer/blob/master/docs/release-closeout-0.6.1.md)。本版本只由完整Windows CI及三路隔离安装/升级/重装/卸载检查通过后的同一提交发布；完整失焦报告作为诊断警告保留，有效超阈值仍失败，不以CI绿色声称性能或人工验收全部完成。

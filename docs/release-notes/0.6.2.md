# ModernImageViewer 0.6.2

0.6.2是浏览错误恢复与预览性能补丁，保留0.6.1的格式、动画、多页和编辑范围，不增加新格式或编辑功能。

## 修复与改进

- 缺失或损坏图片打开失败时保留已显示画面，再按方向键可以从失败项继续浏览，不再反复尝试同一个错误文件。F5、新输入和排序重置导航意图；文件夹位置仍对应实际显示图片。
- 对不需要缩小的普通无profile RGB WIC预览复用已读取frame，避免重复初始化。
- 常规8位、非交错、无ICC/eXIf的BGR24/BGRA32 PNG预览、缩略图及有明确预算的完整细节直接使用Windows内置Microsoft WIC会话，在同步作用域释放，减少WPF原始frame源尺寸内存压力引起的完整GC。不增加整图BGRA副本、外部分发依赖或强制GC。
- 带ICC/eXIf、高位深、交错及其他不满足条件的PNG回退既有WPF路径；固定像素/元数据逐字节对照旧路径。无预算完整解码及区域解码沿用旧路径，缓存预算、过期结果保护及原文件只读约束不变。

主动细节性能修复仍在验证，发布暂停；最终候选失败及后续局部测量分别记录，不把本机收益当作原CI门槛验收。

## 验证和限制

PR #48的Windows CI为619通过/1项真实RAW样本跳过，两组各6对有效性能对照在原10%门槛内；这是固定环境的小样本验证，不是P95或跨设备速度承诺。此前有效性能失败和失焦记录保留，0.6.1的风险批准不延用。发布由同一最终master完整CI及全新安装、公开0.4/0.6.1升级、重装和卸载检查全部通过后执行；最终证据见[0.6.2验收](https://github.com/Flysoft1337/ModernImageViewer/blob/master/docs/release-closeout-0.6.2.md)。

完整真实桌面视觉/鼠标、Shell默认应用、混合DPI及跨设备长期低内存人工验收仍有缺口，不能以自动化通过代替。运行中的native解码仍须真实返回才能释放；像素预算不是进程内存上限。RAW仅内嵌预览，AVIF/HEIF仅静态首图；显示器ICC、HDR/高位深输出和完整RAW显影未支持。安装器未签名，仅提供Windows x64。原文件和已发布旧资产不被覆盖。

## 动画与多页浏览

- GIF/WebP 动画自动播放，支持暂停、继续、重播、帧定位及有限/无限循环；按局部区域、透明、混合和 disposal 合成。
- 修复 WebP ANIM 背景兼容：透明、半透明及不透明背景与局部帧销毁一致；Source透明像素正确替换，Over透明像素保留已有画布，代表帧/缩略图/预取与播放首帧一致。
- TIFF 多页浏览支持首页/末页、前后页及直接输入页码，按当前页尺寸和方向解码；单页 TIFF 保持静态图片行为。
- 帧控件按需显示，保持中英文与深浅主题一致。`Ctrl+Space` 播放/暂停，`Ctrl+PageUp/PageDown`、`Ctrl+Home/End` 定位帧/页；左右方向键继续切换文件，F1 帮助同步。
- 图片内部动画与 F6 文件幻灯片分别计时。后台、不可见和最小化暂停呈现，恢复不会解除用户手动暂停；切图、F5 和关闭释放旧会话并拒绝晚结果。
- 同一动画换帧保持缩放、平移和查看方向；TIFF 换页重置视口，同页细化保持视口。缩略图和邻图预取只使用代表帧/首页。

## 0.5 浏览能力

沿用按视口及 DPI 选择首屏预览、前台优先解码、有界缓存与细化、排序、会话旋转/翻转、剪贴板输入和安全新文件导出。普通 JPG/PNG 不创建动画会话或计时器。AVIF/HEIF 仍为静态首图，RAW 仍为内嵌预览；本轮不增加编辑工具。

## 使用边界

动画单帧输出最多 8MiB，应用帧/参考/交接预算 32MiB，不预展开全部帧；源画布 BGRA 等价值最多 92MiB 才准入播放。这些数值不是 native 或整个进程内存硬上限。小于 20ms 的动画延时按 100ms 处理；损坏及超限文件不保证完整播放。

不支持 APNG、AVIF/HEIF 序列、ICO 尺寸选择、动画/多页编辑或动画导出。显示器 ICC、HDR/高位深输出、完整 RAW、可信签名和 MSIX 尚未完成。安装器与便携包自带 .NET，安装器暂未签名，不自动修改默认文件关联。

详细能力、固定样本与验收范围见 [格式支持](https://github.com/Flysoft1337/ModernImageViewer/blob/v0.6.0/docs/decoder-support.md) 和 [已知限制](https://github.com/Flysoft1337/ModernImageViewer/blob/v0.6.0/docs/known-limitations.md)。

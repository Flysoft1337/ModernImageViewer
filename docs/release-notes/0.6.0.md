# Modern Image Viewer 0.6.0 公开测试版

本次为**Pre-release（公开测试版）**，面向v0.4.0用户提供累计更新，包含未单独发布的0.5开发阶段成果。最新稳定版仍为v0.4.0。真实桌面鼠标/视觉、Shell双击、混合DPI和跨设备低内存验收仍有缺口；本次公开测试不表示这些项目已通过。

## 新增格式支持

- 支持范围从 9 个扩展名增至 12 类、25 个扩展名，统一用于打开、目录/多选浏览、缩略图和打开方式候选注册。
- AVIF、HEIF/HEIC 支持静态首图和容器方向纠正，透明依编码变体支持，嵌入 RGB ICC 转为 sRGB；不播放序列，不保证 HDR。源图最多 32MP、输入文件最多 128MiB，解码依赖随包提供。
- DNG、CR2、CR3、NEF、ARW、RAF、RW2、ORF、PEF 支持可读的 RAW 内嵌预览；显示尺寸和编辑对象均为预览，不进行完整显影，不保证所有机型或编码。输入最多 256MiB、内嵌预览最多 32MiB；无可读预览时明确提示。
- 受限 SVG 支持基础形状、路径、变换和本地渐变，按目标尺寸栅格化；不支持文字、图片、脚本、外部资源、use、裁剪/蒙版、滤镜或动画。编辑后导出位图，不回写矢量。
- JPEG XR / HD Photo（`.jxr/.wdp/.hdp`）支持 WIC 可读变体的主图、缩略图和区域细化，输出为 8-bit，不承诺 HDR/高位深输出。
- 静态 WebP 补齐 EXIF 方向 1–8 与嵌入 RGB ICC 转 sRGB；这不代表完整显示器色彩管理。

## 编辑、标注与安全导出

- “更多 → 编辑图片”或 `Ctrl+E` 打开编辑窗口：支持拖选/数值裁剪，自由、原比例及 1:1、4:3、3:2、16:9、9:16 比例，任意角度旋转、90° 旋转/翻转，以及按比例缩放或拉伸。
- 提供曝光、亮度、对比度、Gamma、饱和度、色温、锐化和模糊八项调整，实时预览、重置及撤销/重做共用编辑参数。
- 提供箭头、矩形、椭圆、画笔、中英文文字、马赛克和区域模糊七种标注，可选择、移动、修改和删除，调整颜色、线宽、字号或强度。
- 最多 64 步历史；`Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做，`Ctrl+S` 另存为。关闭时保护未导出修改；失败或取消保留编辑，保存后仍可撤销。
- PNG、JPEG、有损/无损 WebP 只导出到新文件，不覆盖原图或已有目标；提交前检查源版本，失败/取消清理临时文件。PNG/WebP 保留透明，JPEG 使用白底；有损品质 1–100，品质 100 不等于无损。
- 默认移除原始元数据，可选择保留相机、镜头、日期及曝光等安全摄影信息；移除 GPS、缩略图、XMP 和厂商字段。支持的 RGB ICC 转为 sRGB，输出嵌入新的 sRGB profile，不保留原 profile。
- 尺寸、裁剪比例、导出格式/品质、WebP 无损和摄影信息开关可保存为最多 16 个命名预设。文件与剪贴板图片均可编辑；RAW 仅编辑内嵌预览，多帧/多页禁用编辑。

## 浏览、剪贴板与偏好

- 新增名称、修改时间、文件大小的升降序排序，保留当前图片和视口；多选保持选择顺序。`Ctrl+Shift+E` 在资源管理器定位当前文件，`F1` 打开快捷键帮助。
- 查看方向支持左右旋转 90°、水平/垂直翻转和恢复；`Ctrl+R` / `Ctrl+Shift+R` 向右/左旋转，只改变会话显示，不修改文件，切图重置。
- 保存窗口位置/大小、最大化状态、信息面板、缩略图带、排序和幻灯片间隔等偏好，兼容旧设置，恢复窗口时按工作区和 DPI 校正；启动不自动打开历史图片。窄窗口使用紧凑工具条，全屏闲置 2.5 秒后隐藏浮层和光标，操作后唤回。
- `Ctrl+V` 支持文件列表、透明 PNG 和兼容位图；文件列表优先（最多 128 项），PNG 优先于位图。读取失败保留当前图片，文本框使用自身粘贴；内存图片没有文件路径，不提供目录导航、排序或文件定位，可编辑并安全另存。
- `Ctrl+C` 复制整图预览（最大 2560×1600），保留查看方向和 PNG 透明，排除界面及局部细化区域。原尺寸复制仅在完整像素已加载且不超过 64MiB 时可用，不为复制自动读取整图；动画/多页只复制当前已显示的帧/页快照。
- 首屏预览由固定尺寸改为按可见画布和 DPI 自适应，单边最多 4096、像素最多 32MiB，不放大原图；窗口稳定后按需升级，交接保留画面与同来源视口。适应窗口不自动读取整图，放大/实际像素才请求细节。
- 增加 WIC 有界区域细化和单张邻图预取，前台打开优先；连续导航累计目标，只提交最新请求。F5 开始即取消旧请求并清理缓存，过期结果不能回填；失败或超预算保留已有画面。

## 动画与多页浏览

- GIF/WebP 动画自动播放，支持暂停、继续、重播、帧定位及有限/无限循环；按局部区域、透明、混合和 disposal 合成。
- 修复 WebP ANIM 背景兼容：透明、半透明及不透明背景与局部帧销毁一致；Source透明像素正确替换，Over透明像素保留已有画布，代表帧/缩略图/预取与播放首帧一致。
- TIFF 多页浏览支持首页/末页、前后页及直接输入页码，按当前页尺寸和方向解码；单页 TIFF 保持静态图片行为。
- 帧控件按需显示，保持中英文与深浅主题一致。`Ctrl+Space` 播放/暂停，`Ctrl+PageUp/PageDown`、`Ctrl+Home/End` 定位帧/页；手动定位暂停播放，左右方向键继续切换文件。
- 图片内部动画与 `F6` 文件幻灯片分别计时，内部换帧/页不重置文件停留时间，也不等待动画播完。后台、不可见和最小化暂停呈现，恢复不会解除用户手动暂停；切图、F5 和关闭释放旧会话并拒绝晚结果。
- 同一动画换帧保持缩放、平移和查看方向；TIFF 换页重置视口，同页细化保持视口。缩略图和邻图预取只使用代表帧/首页。
- 常规静态图、单帧 GIF、静态 WebP、单页 TIFF 不显示帧控件，也不建立活动帧会话或启动动画时钟。

## 使用边界

动画单帧输出最多 8MiB，应用帧/参考/交接预算 32MiB，不预展开全部帧；源画布 BGRA 等价值最多 92MiB 才准入播放。这些数值不是 native 或整个进程内存硬上限。小于 20ms 的动画延时按 100ms 处理；损坏及超限文件不保证完整播放。WebP Over 按预乘 sRGB 合成，未实现线性光混合。

剪贴板图片源像素载荷最多 64MiB、PNG 编码最多 32MiB，不接受高位深输入。编辑常规源/输出各最多 64MiB；启用调整时输出最多 32MiB，预览效果为降采样近似，最终以导出为准。WebP 无损不代表保留原文件编码、高位深或所有半透明通道的逐值一致。

WIC 区域细化限单个 2048×2048/16MiB 区域，没有完整分块缓存；WebP 无区域解码。已执行的 native 解码不保证立即取消；未启用持续文件监听，同路径内容变化但时间戳/大小不变时需 F5。

不支持 APNG、AVIF/HEIF 序列、ICO 尺寸选择、动画/多页编辑或动画导出。BigTIFF 全面兼容、TIFF 嵌入 ICC 转换、显示器 ICC、HDR/高位深输出、完整 RAW、可信签名和 MSIX 尚未完成；不保证所有格式变体可读。Windows x64 安装器与便携包自带 .NET，安装器暂未签名，仅注册打开方式候选，不自动修改默认文件关联。

## 验收与未解决问题

准备基线master `5c024fb`的[完整Windows CI](https://github.com/Flysoft1337/ModernImageViewer/actions/runs/37876822463)为599项通过、1项真实RAW样本跳过，包含格式、Release构建、审计、100MP、启动、文件激活、浏览、动画及实际0.5→0.6升级/重装/卸载。最终发布提交仍须通过同一条CI，安装包由该次运行产生并附SHA256；不把基线CI冒充发布运行。本机实际150%DPI动画自动驱动已通过，不能替代公开v0.4.0直升或完整人工验收。

上一同机八组交替 PNG 观察中候选首图比同批 0.5 偏慢约22.2ms；随后用完全相同二进制再做八组，首图中位数106.71/108.11ms、差约1.41ms，配对差值中位数0.22ms，未复现稳定22.2ms开销。诊断复测也未见同等差异，但尚未确认具体波动原因，目录导航时点仍有疑点；没有接受超过10%回归的发布豁免。这不是与公开 v0.4.0 的性能对照，不承诺所有静态格式零退化、冷启动达标或 P95。

真实窗口视觉/鼠标拖拽、混合 DPI 多屏、跨设备低内存长测，以及真实外部应用剪贴板互通、持久系统剪贴板、默认应用选择/Shell 双击的完整人工验收仍有缺口；自动化驱动和合成截图不能替代这些检查。

详细能力与边界见 [格式支持](https://github.com/Flysoft1337/ModernImageViewer/blob/v0.6.0/docs/decoder-support.md)、[编辑能力](https://github.com/Flysoft1337/ModernImageViewer/blob/v0.6.0/docs/editing-improvements.md)、[已知限制](https://github.com/Flysoft1337/ModernImageViewer/blob/v0.6.0/docs/known-limitations.md) 和 [收口验收](https://github.com/Flysoft1337/ModernImageViewer/blob/v0.6.0/docs/release-closeout-0.6.0.md)。

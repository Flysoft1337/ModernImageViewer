# 编辑能力与验证

## 当前开发能力（2026-10-06）

0.5.0 开发代码已接入任意角度旋转及扩大后的透明画布、90°旋转/翻转、自由和固定比例裁剪、Resize/Stretch、64步参数历史与关闭保护。任意旋转的区域逆变换使用视口四角；裁剪数字和拖选均对应 EXIF 校正后的源坐标，任意倾斜时显示源裁剪四边形，比例定义在90°方向后的源裁剪区域，倾斜画布的包围盒不保证该比例。

调整页提供曝光、亮度、对比度、Gamma、饱和度、色温、锐化和模糊。拖动实时预览，松开或键盘步进后提交一次历史；撤销、重做、重置和保存均使用同一参数模型。同尺寸调整保留当前缩放和位置。颜色滤镜保留 alpha；空间滤镜作用于完整合成输出，避免逐块导出产生滤镜接缝。预览降采样不代表原尺寸像素精度，锐化缩略预览为近似，最终以导出为准。

标注页提供箭头、矩形、椭圆、画笔、文字、马赛克和区域模糊，支持中英文文字及颜色、线宽、字号和强度。绘制、选择移动、修改和删除使用源坐标参数；最多128个标注、单笔2048点、总16384点、单文字512字符/总8192字符。拖动草稿可取消，不改变原像素。区域隐私处理在写回前完成有界采样，裁剪/旋转/翻转后仍限定选区。

导出提供 PNG、JPEG、有损/无损 WebP；JPEG白底，PNG/WebP保留透明；有损品质1–100，品质100不等于无损。WebP无损使用 VP8L 编码模式，8位预乘 BGRA 与直通道之间的半透明量化可能相差一个预乘通道值，不承诺无损保存原文件编码或高位深数据。只创建新文件，不覆盖源或已有目标，源版本和只读锁保持至提交；失败、取消清理两个阶段的临时文件。

默认移除原始元数据；可保留相机、镜头、日期、ISO、曝光、光圈、焦距。输出方向为1、尺寸更新，GPS、缩略图、XMP、厂商字段不复制。WIC RGB ICC 在编辑预览及导出转换至 sRGB，WebP/AVIF/HEIF沿用已转sRGB的解码输出；没有profile按sRGB解释。输出明确嵌入新sRGB profile，不提供“保留原profile”选项。非RGB设备profile、显示器ICC、HDR和高位深编辑仍未完成。RAW继续仅编辑内嵌预览。

尺寸、裁剪比例、导出格式/品质、无损和摄影信息开关可保存为最多16个命名预设，复用原设置文件并兼容旧设置。应用预设先写入参数草稿，正常应用/保存进入历史；不保存文件路径或原像素。

源/常规输出各最多64MiB；启用调整时按输出及三个保守工作surface限制至128MiB（输出最多32MiB）。效果/标注/色彩转换预览最多8MiB、最长边2048；中性且无需转换时不增加像素缓存。区域遮挡每个采样/模糊局部缓冲最多4MiB，超大区域降采样。Skia/native/codec/surface与编码内部内存不全计入这些限制，不称整个进程硬上限。

本批验证与 CI 的实际结果见[进度记录](planning/progress.md)。开发版本仍0.5.0，最新公开下载仍v0.4.0，不触发Release。

## 未导出修改保护（2026-10-06）

编辑器关闭时，如果当前裁剪/方向/尺寸不同于最近成功导出的状态，或数值字段还有未应用的修改，将提示“继续编辑”“丢弃修改”“另存并关闭”。首次打开且没有编辑时直接关闭；导出成功只更新参数检查点，不清空撤销历史。撤销到其他状态会再次提示，重做到已导出状态则不提示。仅切换格式/品质不视为图像编辑。

取消文件选择、校验失败或导出失败均保留编辑窗口；导出期间关闭先取消任务，结束后重新判断是否存在未导出修改，不能自动丢弃。确认时禁用底层编辑，焦点默认在继续编辑，Tab在确认操作中循环；Esc返回编辑并恢复焦点。文件与内存来源共用这一行为，只增加轻量recipe引用，不增加像素副本。本地Release构建0警告/0错误，核心4及双语/STA窗口12项通过，深中文/浅英文720×480确认截图已查看；正式Windows CI随后记录。

# Windows 双击图片与文件关联方案

> 更新日期：2026-10-04。状态：A1–A3 应用端与便携注册已实现；A4 本轮新增 0.2.0 当前用户 EXE 安装器，MSIX 待实现。Windows CI 已配置安装、激活、升级与卸载检查，结果见对应运行记录；真实 Windows 默认选择/资源管理器双击、移动路径与卸载边界仍需按下述人工步骤验收。

## 0. 安装版使用方法

1. 运行 `ModernImageViewer-0.2.0-win-x64-Setup.exe`，面向 Windows 10 22H2/11 x64。默认安装到当前用户 `%LOCALAPPDATA%\Programs\ModernImageViewer`，无需管理员权限；包内含 .NET/WPF 与发布输出中的 native 依赖。当前安装器未签名。
2. 按需勾选 JPEG/PNG 打开方式候选，完成安装；也可稍后从应用右上角“设置 → 用此应用打开图片”注册或修复。开始菜单可启动应用，桌面快捷方式可选。
3. 在 Windows 默认应用或图片“打开方式”选择 `Modern Image Viewer`，分别设置 `.jpg`、`.jpeg`、`.png`；安装器不会代替用户设置默认应用。
4. 资源管理器双击图片，应用已打开时复用同用户同会话的窗口。安装版与便携版候选可共存，名称分别为 `Modern Image Viewer` 与 `Modern Image Viewer (Portable)`。
5. 升级使用同一安装身份与原安装位置；卸载通过 Windows 已安装应用或开始菜单入口。卸载仅清理仍归当前安装 EXE 所有的关联值，不撤销便携版、其他应用候选或用户主题/语言偏好；Windows 对失效默认项的提示按系统规则处理。

安装版不要直接搬动文件夹，需改路径时通过安装器安装到目标位置并核对注册。MSIX 和可信签名发布尚未交付。

### 便携版使用方法

1. 将 self-contained win-x64 发布包解压到准备长期保留的位置，运行 `ModernImageViewer.App.exe`。
2. 打开右上角“设置 → 用此应用打开图片”，点击“注册打开方式”。界面显示注册状态与注册 EXE 路径；缺失的注册项可重新注册修复，也可取消。
3. 点击“选择默认应用”，在 Windows 默认应用设置或图片“打开方式”中选择 `Modern Image Viewer (Portable)`；按需要分别设置 `.jpg`、`.jpeg`、`.png`。
4. 在资源管理器双击图片；再次打开另一张会复用同用户同会话的窗口。窗口最小化时恢复；Windows 拒绝前台激活时闪烁任务栏。
5. 移动应用后，在新位置重新注册；删除应用目录前在当前注册副本取消注册。旧副本不能取消新副本的注册。便携版不具备安装器的升级/卸载钩子。

开发运行与框架依赖 apphost 不提供注册按钮操作；使用发布包。注册不设置默认应用，也不改写图片。

## 1. 用户期望

安装后，Modern Image Viewer 出现在 JPEG/PNG 的“打开方式”和可选默认应用中。用户选择它作为对应格式默认应用后，资源管理器双击图片即启动并显示该图片；应用已打开时，后续打开请求复用窗口并切换到新图片。

Windows 10/11 的默认应用由用户在系统界面选择。注册关联是提供候选处理程序，不等于自动成为默认应用；应用不能静默抢占默认应用，也不写入或伪造 `UserChoice`。应用内提供“文件关联”设置说明与打开系统默认应用设置的入口。

当前“画布内双击切换适应窗口/实际大小”继续保留；本文处理的是资源管理器双击文件。

## 3. 应用端接入

### 3.1 统一打开请求

将外部激活转换成 `OpenRequest`（来源、路径列表、请求序号），交给现有 `OpenInputAsync` / 图片打开管线。普通命令行和 MSIX 激活采用各自的入口适配，最终共用路径校验、取消、错误状态与导航；不要直接把 UWP 的激活 API 当成现有 WPF 启动事件。

- 保留无参数欢迎页、图片/文件夹参数；参数解析不得将中文、空格、括号、`&` 等路径字符当成 shell 命令。
- 单个外部请求只含图片时直接打开；多选同目录建立临时选择序列并显示第一张，混合目录也按输入列表建立序列，不在启动时一次解码所有文件。普通单图继续使用同目录导航；临时序列的来源在 UI 中说明。
- 不存在、无权限、损坏、不支持的路径均提示；一组多选无效项可略过并汇总，全部无效时保留旧图/欢迎页。
- 新请求使过期加载与目录任务取消，结果提交前核对序号。未来有未导出编辑时，先完成保留/丢弃/取消选择，不能无提示替换编辑会话。
- 激活传来的路径仍是不可信输入；只按文件/目录读取，不执行路径、不打开网络协议，不以高权限处理图片。

### 3.2 已有窗口复用

近期默认一个主窗口，重复激活通过当前用户范围的命名互斥体与受限 IPC 转交路径。首次实例负责监听，后续实例确认请求已被接收后退出；限制消息大小、路径数量、连接等待与重试次数，避免 UI 线程等待 IPC。

启动竞态、首个进程未就绪、崩溃残留和管道断开都要处理；失败提供可理解的错误或有限重试，避免丢文件请求和无限进程循环。检查消息来源与当前用户权限，不将管道设计成通用命令执行接口。

恢复已最小化窗口并按 Windows 前台规则请求激活；系统拒绝抢焦点时闪烁任务栏提示。请求能进入隐藏/全屏窗口，不能因等待前台权限而不打开图片。多窗口作为后续显式选项，当前每次激活创建新进程的行为不作为最终方案。

## 4. 关联注册与安装

### 4.1 当前 EXE 安装器

- `scripts/build-installer.ps1` 发布或复用 `artifacts/publish/win-x64`，包含完整 self-contained 输出，再用固定版本并校验 SHA-256 的 Inno Setup 编译器打包。安装器源为 `packaging/windows/ModernImageViewer.iss`，输出 `artifacts/installer/ModernImageViewer-0.2.0-win-x64-Setup.exe`；同时生成便携 ZIP 和校验清单。构建要求 Windows 与 PowerShell 7。
- 使用稳定 AppId 升级，当前用户安装；默认安装位置、开始菜单与可选桌面入口由安装器管理，不要求 UAC 提权。卸载只删除安装器管理的文件，保留应用在用户本地设置目录中的主题/语言偏好。
- 安装标记使应用关联设置识别安装版，便携 ZIP 不带该标记。安装版 ProgID `ModernImageViewer.Installed.Image`、应用 ID `ModernImageViewer.Installed`、所有者标记 `ModernImageViewer.Installed.v1`，便携版保持 `ModernImageViewer.Portable.*`。
- 安装、修复和卸载的注册内容与应用服务保持一致；打开命令分别引用 EXE 与 `%1`。卸载校验所有者和 EXE 路径，只删除值仍匹配的候选、能力和专属命令；不盲删共享扩展名键、不改写 UserChoice。
- Windows CI 的安装 smoke 应覆盖含中文/空格安装路径、真实 EXE 两次打开、同身份升级、卸载清理与偏好/其他候选保留。该自动化不选择系统默认应用，Shell 双击按人工步骤另验。
- 当前没有可信代码签名，MSIX 不使用临时自签证书冒充正式发布。后续签名证书与私钥不进入仓库。

### 4.2 后续 MSIX

1. 建立打包工程/manifest，固定包身份与应用 ID；包含图标、名称、受支持文件类型及实际 native 运行依赖。
2. 按打包的全信任 WPF 程序模型声明文件类型关联，确认扩展入口、参数传递和重复激活行为；用真实安装包验证，不能只用 `dotnet run` 代替。
3. 开发测试签名与正式签名分开；正式发布需要受信任签名和可持续的升级身份。证书/私钥不进入仓库。
4. 验证同身份升级保留关联候选，卸载清除包注册且不影响其他应用；用户默认选择与偏好行为按系统规则说明。

### 4.3 便携版可选注册

当前用户注册在 `HKCU\Software\Classes` 建立应用专属 ProgID、图标与 `shell\open\command`，为扩展名加入对应 `OpenWithProgids`；提供应用能力注册与 RegisteredApplications 项，使支持类型能被系统识别。键名和 ProgID 在实现时固定，注册信息仅指向当前可信 EXE。

打开命令的语义必须为：

```text
"C:\Apps\ModernImageViewer\ModernImageViewer.App.exe" "%1"
```

EXE 与文件占位符分别引用；使用注册 API 写入值，不通过字符串拼接调用 `cmd.exe` 或 shell。不得覆盖扩展名的其他 ProgID、其他应用的关联候选或用户默认选择。

注册成功后通知 Shell 关联变化，用户自行在系统界面选择默认程序。取消注册仅删除本应用创建且仍归本应用所有的值；若 EXE 路径已变或另一个便携副本接管注册，不盲目删除。工具支持显示当前注册路径、重新注册与取消注册，无需管理员权限。

便携版没有安装器卸载钩子，README 提示先取消注册再删除文件夹；不要把移动 ZIP 的规则套用于安装版。

## 5. 任务拆分与精简验收

| 顺序 | 交付 | 关键验证 |
|---|---|---|
| A1（已实现） | 外部打开请求模型与路径/多选适配 | 顺序、过滤、全部失败保留、过期请求已加回归；混合输入只取显式图片，单图维持目录导航 |
| A2（已实现） | 当前用户单实例 IPC、恢复窗口与重复打开 | IPC ACK、超限、超时/取消已加回归；发布包 smoke 打开两张图片并验证次进程退出；最小化/全屏和崩溃重试人工验收 |
| A3（已实现） | 便携可选注册/取消注册与用户说明 | 隔离注册根回归覆盖引用、接管、部分清理及其他候选保留；真实 Shell 候选、默认选择、移动/清理人工验收 |
| A4（本轮 EXE） | 当前用户 EXE 打包、独立安装候选、升级/卸载；可信签名与 MSIX 后续 | Windows CI 安装/激活/升级/卸载结果见对应运行记录；Windows 10/11 默认选择与实际双击、签名、长路径边界另验 |

功能级自动化仅覆盖参数、请求竞态与注册信息生成等关键逻辑；文件关联必须做实际 Windows Shell 验收，日常文档修改不增加全套测试矩阵。验收记录包括系统版本、包/EXE 版本、安装方式及默认应用选择步骤。

### 人工 Windows Shell 验收

- Windows 10 22H2 / Windows 11 普通用户运行发布包，注册后在打开方式/默认应用中可找到候选；选择三种扩展后分别实际双击。
- 图片与 EXE 路径含中文、空格、括号、`&`；无参数重复启动、窗口最小化/全屏、连续打开多文件；确认旧图不会覆盖最后请求。
- 不支持/损坏/已删除图片有反馈；全部失败保留当前显示；多选按顺序，F5 不扩充为整个目录。
- 移动发布包后新副本重新注册；旧副本不能取消新注册；当前副本取消后候选清理，其他应用选项不变。Windows 可能提示重选默认应用，应用不伪造 UserChoice。
- 安装版与便携版同时注册后均能选择；安装版升级保留正常候选，卸载清理归属当前安装的值且不影响便携版和其他应用。偏好目录保留，卸载后再次安装可读取既有主题/语言选择。
- 关闭主窗口后无残留主进程，重新启动正常；首个进程崩溃或无响应时后续请求有限等待并提示重试。

CI 的 `check-file-activation.ps1` 验证真实 EXE 的命令行与已有窗口转发，不设置系统默认应用；本轮安装检查另外验证临时测试目录中的安装器与候选生命周期。隔离注册表单元测试不触及系统 Classes；这些检查不能替代上面的 Shell 验收。检查结果以交付 PR 和对应 CI 运行记录为准。

文件关联任务属于 M1 日常打开体验，复杂右键转换和进程内 Shell 扩展仍留到 v1.x。

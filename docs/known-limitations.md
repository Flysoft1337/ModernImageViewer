# 0.6.0 已知限制

当前源码为 0.6.0 发布候选，尚未发布；公开下载仍为 v0.4.0。本页与 [格式矩阵](decoder-support.md) 描述候选代码的实际范围，历史下载包不因此获得新能力。

## 动画与多页

- GIF/WebP 支持播放、暂停、重播、帧定位及有限/无限循环；低于 20ms 的帧延时按 100ms 处理。坏帧反馈错误并保留最后有效画面，不保证所有损坏或编码变体可读。
- WebP ANIM 背景与局部帧已用固定像素回归验证，Over使用预乘sRGB计算，没有线性光混合；嵌入RGB ICC在帧与背景使用同一sRGB转换。
- 多页 TIFF 使用系统 WIC；支持逐页尺寸、方向和当前页细化。BigTIFF 全面兼容、TIFF 嵌入 ICC 转换未完成；不可读后页 IFD 可能使整个分页会话无法建立。
- 多帧 GIF/WebP、多页 TIFF 禁用静态编辑；复制图片只复制当前已显示帧/页。缩略图与邻图预取保持静态代表帧/首页，不能导出动画或整个多页容器。
- APNG、AVIF/HEIF 序列、ICO 多尺寸选择未实现；AVIF/HEIF 仅首图，RAW 仅内嵌预览，没有完整显影。

## 资源与图像质量

- 动画单输出最多 8MiB，应用持有的帧、合成参考及交接像素按 32MiB 预算处理，不永久展开所有完整帧。源画布 BGRA 等价数据量最多 92MiB 才准入播放；超限尝试静态代表帧并反馈。
- 上述预算不涵盖所有 native codec 工作区、绘制 surface、运行时和进程资源。代表帧降采样也可能使用源尺寸 native 工作区，不承诺整个进程内存硬上限或绝不泄漏。
- 输出为预乘 BGRA8；动画大画布按预算降采样。WebP 无区域解码，WIC 区域为单个 2048×2048/16MiB 视区，没有完整分块缓存。
- 已执行的 native 解码不能保证立即取消。切图/F5/关闭使旧结果失效，真实返回后释放；取消不等于 codec 已立即停止。
- 显示器 ICC、HDR、高位深输出及所有广色域变体的准确色彩未完成。静态 WebP 的 RGB ICC 转换与方向纠正不等于完整色彩管理。
- 未启用持续文件监听；同路径内容改变但时间戳/大小均不变时需要 F5。原图始终只读，编辑导出使用新文件。

## 验证与分发

自动化 DPI 覆盖 100/125/150/200%，本机实际150%DPI动画自动驱动和安装升级检查通过；截图工具持续超时，真实窗口视觉/鼠标拖拽、混合 DPI 多屏及跨设备低内存长测尚未完成，合成截图不替代人工验收。同机八组交替复测中候选首图比同批0.5偏慢约22.2ms，切图中位数接近，不承诺所有静态格式零退化。阶段观察仅在显式启用时运行，不持续记录普通用户路径或性能日志；小样本对照不作为冷启动或 P95 承诺。

仅提供 Windows x64、当前用户 EXE 安装器和便携 ZIP；安装器尚未签名，MSIX 未提供。安装器注册打开方式候选，不自动抢占系统默认关联。Shell 默认应用选择和完整跨设备人工验收仍需单独完成。

本轮实际结果见 [Release 收口验收](release-closeout-0.6.0.md)，上一轮固定样本和资源验收见 [动画与多页记录](animation-multipage-validation.md)。

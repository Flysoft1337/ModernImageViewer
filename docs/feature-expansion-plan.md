# 下一批功能实施方案

## 2026-10-09：0.6.0 Release 收口范围

GIF/WebP/TIFF统一帧能力已交付，本轮只复测静态性能、修复WebP ANIM背景兼容、实际Windows动画/DPI/安装升级和发布资料；不增加编辑、标注、滤镜、批处理或大型功能。WebP新增29项固定像素回归，本地完整598通过/1跳过；最终候选与CI证据见[收口验收](release-closeout-0.6.0.md)，能力与未完成项以[支持矩阵](decoder-support.md)和[已知限制](known-limitations.md)为准。

## 2026-10-06：0.6 最新状态覆盖

用户已确认[动画与多页方案](animation-multipage-plan.md)。N4的GIF/WebP动画与TIFF多页已通过固定样本与Windows CI，实际边界和569通过/1跳过、安装及压力结果见[验收记录](animation-multipage-validation.md)；ICO多尺寸仍未实现。当前源码为0.6.0未发布开发版，最新公开下载仍为v0.4.0。本节覆盖下文历史段落中的“N4待实现”，保留历史验证，本批继续冻结编辑范围，不扩完整RAW。

实际支持按[static/animation/pages/transparency/ICC/EXIF/region/edit矩阵](decoder-support.md#当前能力矩阵)：单帧GIF、静态WebP、单页TIFF与常规静态图无帧控件或动画时钟；F6是独立文件幻灯片，内部播放/翻页不重置它。动画提供暂停/重播/定位与有限/无限循环，手动定位暂停；TIFF按页尺寸/方向读取，换页清除旧页ROI，同页细化保留视口。多帧/多页禁止编辑，剪贴板只取当前已显示快照，不重读原路径或隐式导出整段动画。

动画按目标解码、单输出最多8MiB，应用掌控帧/参考/交接按32MiB处理并纳入已有主图边界；source的 `宽×高×4` 最多92MiB才准入，这是native工作区的源尺寸规则，非进程cap。TIFF页用静态32MiB预览/92MiB完整细节和2048×2048/16MiB区域预算，完整页无4096强限。native真实返回后才完成取消和释放晚结果，Dispose不阻UI，ReleaseCompletion用于真实释放观测。输入256MiB、帧/页10,000、元信息2MiB及源32768单边/100MP限制继续适用。

固定样本/生命周期、双语主题UI/F6、混合压力、Windows CI与真实升级安装验收已记录；固定机静态性能与混合DPI/跨设备长测仍待补。单次CI静态时间偏慢，不写成性能无退化。新增能力不替代性能测量，不触发Release；已有[浏览收口](browsing-core-closeout.md)和[格式编辑记录](raw-modern-editing.md)保留各自历史范围。

## N1：日常浏览

### 排序

接入点是 `Application/Browsing/ImageBrowseSession.cs`，现有 `BrowseSnapshot` 与 `_revision` 已保护异步索引；`Enumerate`、`CommitSnapshot` 和 `RefreshAsync` 都要沿用同一个排序策略。`NaturalFileNameComparer` 继续负责自然名称比较。

- 默认自然名称升序；时间/大小主键相同时按自然名称、完整路径稳定排序。无法读取属性的条目放在末尾，切换升降序仍保持这一规则。
- 文件属性只在选用对应排序时，在后台读取一次并组成快照；比较器不调用 `FileInfo`。快速切换模式取消旧任务，只有当前目录/请求代次可提交。
- 切换排序重新定位 `CurrentPath`，不重新解码当前主图，不改变缩放、平移或已加载区域。更新缩略图序列、首尾导航和幻灯片顺序。
- 显式多选继续保持输入顺序，排序菜单禁用并说明原因；不会因一个目录排序偏好重排多选列表。
- 当前图在外部删除时沿用已显示条目保留规则；F5 刷新后继续遵守所选排序。
- 调整导航顺序后取消旧邻图预取，并按新邻居重排预取。现有 `ClearPreviewCache()` 也会清除区域细节，排序应补专用邻图调度入口，避免用 F5 或整图重载代替重排。

已新增 `BrowseSortMode` 与异步排序入口，N2 已扩展设置快照跨启动保存；空会话只初始化排序策略，不扫描目录。关键回归覆盖同键稳定性、快速切换/过期提交、多选顺序、当前图和像素所有权保留，复用已有浏览测试。

### 文件定位

在 `Application/Integration` 定义小型文件定位服务，在 `Platform` 实现 Windows Shell 选择，在 `DependencyInjection.cs` 注入；UI 调用服务并展示结果。优先使用 Shell 的定位/选择 API，避免把完整路径拼接成 shell 命令。现有复制路径功能继续保留。

只在有真实文件来源时提供入口，调用前确认目标存在，网络路径检查在后台进行。Shell 不可用或文件失踪时显示本地化提示，不关闭图片。位图剪贴板来源进入 N3 后禁用定位，保持同一入口规则。

### 快捷键帮助

在 `UI` 建立可被帮助面板读取的命令名称/快捷键目录，先迁移现有快捷键说明，再加入已交付的新命令。帮助面板使用现有主题、字体、卡片和滚动条，按打开、浏览、查看、播放、文件操作分组，快捷键右对齐；支持键盘关闭和焦点恢复，全屏中也能打开。

`MainWindow.xaml.cs` 已跳过文本框、下拉框与菜单中的画布快捷键；新增复制/粘贴等操作继续遵守这条规则。未实现命令不展示为可执行按钮，拟定快捷键在实际接入前不标为已支持。

## N2：查看方向与偏好

### 会话旋转/翻转

当前 WIC 在解码阶段已应用 EXIF Orientation。用户查看变换作用于纠正后的原图，不重复应用 EXIF；切换图片默认重置会话变换。“恢复方向”返回该图的 EXIF 纠正显示，不修改磁盘文件。

扩展 `Imaging` 的视口变换和 `UI/Controls/ImageViewport.xaml.cs` 绘制路径，预览、透明背景及细节区域共用同一变换。90°/270° 交换显示尺寸；实际像素模式保留原始像素密度，鼠标锚点缩放按变换后的坐标处理。

区域请求需要把可见视区逆变换回原图坐标，再受现有 2048×2048 / 16MiB 限制；解码完成后按源区域放置并应用同一查看变换。仅改变绘制矩阵，避免为旋转/镜像分配整图副本。关键回归覆盖旋转与镜像组合、区域位置、平移/缩放、切图重置及快速操作取消。

### 偏好持久化

N2 已扩展 `IUserSettingsService` 的完整快照，`Platform/Settings/UserSettingsService.cs` 继续使用 source-generated JSON 与临时文件替换。所有字段在同一锁下合并，保存语言/主题也保留窗口和浏览偏好；350ms 去抖，关闭完成最后 flush。

新增字段包括正常窗口位置/大小、最大化状态、信息/缩略图面板选择、排序模式和幻灯片间隔；旧 JSON 缺失字段使用现有默认值，非法数值回退。保存合并且短暂去抖，关闭时完成最后写入，避免每次窗口移动同步写盘。

全屏使用此前正常窗口边界，不保存覆盖屏幕的临时位置。恢复时结合当前屏幕工作区与 DPI 校正，显示器移除后移回可见区域；不自动打开历史图片、不新增启动时目录扫描。

## N3：剪贴板与来源模型

已引入文件/内存来源身份。内存图片以独立Guid区分同尺寸的多次粘贴；来源没有FilePath，不伪造目录/定位/复制路径/排序，成功提交后清理导航与邻图预取。取消、损坏与超限保留当前图，晚完成结果释放；按需细化保留方向，换来源重置方向和视口。

Ctrl+V/菜单读取一次STA快照，文件列表优先复用128项限制/筛选/多选顺序，PNG优先保留透明。PNG只在STA有界快照编码和读取头，解码/转换/目标缩放在后台；兼容BitmapSource冻结原来源，预览最多2560×1600，源单边32768/BGRA等价64MiB，编码32MiB。原始位图载荷也核对实际位深，暂不接受高位深；native/剪贴板提供方分配不受这些输出限制保证。

Ctrl+C复制整张图片预览，包含查看方向，不把中心ROI合成为假全图；原尺寸复制只允许已加载完整像素且输出≤64MiB。发布PNG流与兼容Bitmap，PNG透明回归通过不代表所有外部软件的位图Alpha表现一致。像素转换在后台、最终发布回STA并检查取消；新打开/关闭取消晚写，文本输入保留自身复制/粘贴。无方向/不缩小的复制复用已有数组，不额外生成完整托管源副本。

内存图片可进入原有编辑会话及PNG/JPEG/WebP新文件导出，完整像素按需读取≤64MiB或共享现有数组；预览/导出独立只读快照，目标仍临时CreateNew→flush→Move且不覆盖已有文件。完整范围、验证与未验收项见[剪贴板图片记录](clipboard-images.md)。

## N4/N5：帧模型与更多格式

此前N5接入静态AVIF/HEIF与RAW内嵌预览，JPEG XR/受限SVG沿用前批；该批样本、资源和分发证据见[历史验证](raw-modern-editing.md)。0.6的GIF/WebP动画与TIFF多页已通过自动化验收，完整RAW显影和完整SVG仍未交付。

| 能力 | 当前基础 | 首次实现与限制 |
|---|---|---|
| GIF 动画 | 随包SKCodec持久会话，固定像素/CI通过 | 透明/局部/disposal依赖合成；播放/暂停/重播/定位/循环；无动画ROI |
| TIFF 多页 | 系统WIC COM持久decoder/只读流，固定页像素/CI通过 | 页数与定位、每页尺寸/方向；换页丢弃旧区域，同页完整/ROI细化；owned线程确定释放 |
| WebP 动画 | 随包SKCodec持久会话，固定像素/CI通过 | Alpha/Source-Over与依赖帧合成、方向/RGB ICC→sRGB；播放控制/定位/循环；无ROI；ANIM背景颜色兼容修正未完成 |
| ICO 尺寸选择 | 第一图标帧 | 显示可用尺寸，按视口选合适帧；不将图标尺寸列表伪装为动画 |
| AVIF / HEIF | 固定Magick.NET-Q8-x64 14.17.2已接入 | 静态首图/预览/缩略图/预算内细化；32MP/128MiB输入、native全图后缩放；容器方向一次纠正/RGB ICC→sRGB，无ROI/序列/HDR保证 |
| RAW | 固定LibRaw0.22.2预览桥接已接入 | JPEG/RGB8/RGB16内嵌预览、独立方向、有界输出；无预览明确反馈，不解包传感器或显影 |
| SVG | 首批受限开发代码已接入 | 固定Svg.Skia5.2.3，基础形状/路径/本地渐变直接完整目标绘制；拒主动/外部资源及复杂特性，限定输入/几何/透明层预算，完整SVG仍未支持 |

帧能力已使用独立于静态 `IImageDecoder` 的 `IImageFrameSession` 契约：帧/页元信息、按目标和预算读取、携页索引的区域入口、取消、显式Dispose和ReleaseCompletion。GIF/WebP使用SKCodec合成，TIFF复用系统WIC decoder/只读流；单帧/单页返回静态路径。

0.6当前动画按视口目标与8MiB单输出预算降采样，应用掌控帧/参考/交接预算32MiB；source BGRA等价超过92MiB不建立播放会话，尝试保留有反馈的静态代表预览。不预解码整个动画、不按帧数代替字节计费；该准入规则与输出预算都不是native峰值或进程cap。此前首批1280×800是规划值，不是当前动画固定目标。

新native检查实际架构、许可/NOTICE、源码归档/哈希；主图/预览/缩略图、选择器/导航及关联统一接入。已启用静态AVIF/HEIF与九种RAW预览扩展，不承诺所有机型/编码或完整显影。

## N6：文件与内存编辑

编辑窗口复用只读像素和源坐标矩阵，最多64步参数历史，任意角度ROI使用四角逆变换。已接入八项调整、七种标注/选择修改、预设和有损/无损WebP；PNG/WebP透明、JPEG白底。源版本复核与只读handle锁保持至提交，临时CreateNew→flush→Move不覆盖已有文件，失败/取消清理。元数据默认移除，可保留白名单摄影字段；RGB ICC转换和输出声明sRGB，GPS/旧方向/缩略图不带回。常规源/输出各64MiB，效果工作surface另限128MiB，预览8MiB、局部遮挡每缓冲4MiB；并非native/进程上限。关闭保护草稿和未导出修改，保存后仍可撤销。内存来源共用此流程；原profile保留/显示器ICC、高位深仍未完成，实际支持及验证见[编辑能力](editing-improvements.md)。

## UI 与性能约束

底部工具条继续保留导航、缩放和更多入口；新增低频动作进入分组菜单，会话方向与动画播放提供短小状态，编辑/导出使用单独面板。深浅主题、中英文、720×480 与全屏复用现有 Windows 截图验收，新增输入控件时检查 Tab 顺序、焦点恢复和快捷键冲突。

延迟创建帮助、播放、编辑和 codec 会话；未使用时不初始化 native 模块、计时器或监听器。保持主图单槽、缩略图有界缓存、旧任务代次保护和原图像素只读；不得为新功能引入默认全图复制、无限帧缓存或启动时目录扫描。

目录重排与元信息读取不阻塞 UI；以后加入文件监听时使用去抖、失效代次和 F5 兜底。性能观察覆盖首次窗口、图片首帧、切图、取消后稳定内存和长时间浏览，沿用[性能测量条件](next-iteration-roadmap.md#53-测量与验收)，不提前宣称收益百分比。

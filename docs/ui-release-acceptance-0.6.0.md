# 0.6.0 菜单修复与发布前验收

基线 `master eba2818`，分支 `codex/0.6-menu-closeout`。仅修复菜单和局部窗口 UI，保持 0.6.0；不改图片解码、调度、缓存、编辑能力，不创建 Tag 或 Release。公开 [v0.6.0 Pre-release](https://github.com/Flysoft1337/ModernImageViewer/releases/tag/v0.6.0) 的既有包不包含本轮源码修复，也不覆盖该包。

## 已确认问题与修改

| 问题 | 根因 | 修复 |
|---|---|---|
| 深色菜单左侧浅色空槽 | ContextMenu 只覆盖颜色，仍使用系统根模板 | 完整主题根模板，根/子菜单边框、背景、分隔线统一动态资源 |
| 旋转图标消失 | MenuItem 模板只画勾选、标题、快捷键、箭头 | 独立 Icon Presenter 与勾选，自动共享前导列；图标与勾选可以共存 |
| F6/F11 显示两次 | 标题资源含快捷键，同时设置 InputGestureText | 增加菜单专用中英文资源，保留工具栏提示里的快捷键 |
| 屏幕高度不足时选项不可达 | 根/子菜单无受限滚动容器 | 按目标显示器工作区物理像素转 DIP，匹配 WPF Popup 75% 高度限制，内部滚动；保留原生边缘翻转 |
| 关闭按钮焦点/按下反馈缺失 | 特例模板未保留普通按钮状态 | 主题焦点边框、按下颜色和红底白色图标，保留键盘可见反馈 |
| 空状态英文单词拆行 | 支持格式文本使用 Wrap | 改用 WrapWithOverflow，保持原布局 |

菜单事件集中到 `MainWindow.Menus.cs`，复用已有显示器 API 和窗口命令。Popup 保留 `PART_Popup`，ScrollViewer 保留必要模板部件；原生方向键、Enter、Space、Esc 用于菜单导航，已有 Ctrl 组合与 F1/F5/F6/F11 关闭菜单、恢复窗口焦点后交给原快捷键处理。

## 渲染与人工证据边界

18 张本轮菜单 WPF RenderTarget 截图包括空/有图的双语深浅根菜单、查看方向子菜单与 100/125/150/200% 模拟布局。已核对深色中文根菜单、浅色英文查看方向、浅色中文空菜单和 200% 图标加勾选：浅色槽消失，旋转图标、勾选和单次快捷键正常。截图与布局检查沿用 `MIV_UI_SCREENSHOT_DIRECTORY`，由既有 Windows CI 上传；这些是 WPF 渲染结果，不是物理桌面截图或人工鼠标验收。

本轮 Computer Use 只读捕获现有窗口，先后返回 `FrameArrived timed out: timed out waiting on channel` 和 `window capture timed out: timed out waiting on channel`；重新选择当前窗口后重试仍失败，停止桌面输入。当前用户安装版正在运行，本机不执行会向该单实例发送请求的启动/激活/浏览观察，也不执行安装器。完整应用 smoke 交由隔离 CI。
